Automated ETL Pipeline
STEP 01

다각도 타깃 쿼리 순회

단일 검색어(samsung TV)에 의존하지 않고, 브랜드별·시리즈별 10~59개 타깃 쿼리와 카테고리 뎁스(1~12P)를 전수 순회하여 신규 출시 및 이월 모델을 빠짐없이 발굴합니다.

Active Query Traversal
STEP 02

Master Registry 대조

검색 랭킹 변동이나 일시 인덱싱 오류로 인한 샘플 유실을 방지하기 위해 영구 보존된 유럽 전체 2,016개 검증 PDP URL과 실시간 교차 검증합니다.

2,016 Master Models Cross-Check
STEP 03

실시간 라이브 PDP 프로빙

검색 결과에서 일시 누락된 모델은 저장된 개별 상품 URL로 직접 당일 라이브 HTTP/DOM 요청을 발송하여 실시간 판매가와 재고를 확인하며, 품절/단종 모델은 즉시 자동 제외합니다.

Direct Live HTTP 200 Probe
STEP 04

당일 타임스탬프 검증 게이트

모든 유통 원천 데이터가 조사 당일 생성분인지 빌드 시작 시 엄격 검증하며, 과거 캐시나 미수집 유통 발견 시 대시보드 생성을 즉시 중단(Hard Halt)하여 무결성을 보장합니다.

Pre-flight Timestamp Gate

데이터 신뢰성 보증 4대 원칙 (Business Guarantees)

해외영업 멤버들이 바이어 협상 및 내부 보고 시 100% 신뢰할 수 있도록 적용된 데이터 품질 기준

Zero Historical Price Injection (과거 가격 임의 복사 전면 금지)

이전 조사 엑셀의 가격 데이터를 단순 복사하거나 모델을 임의 복원하여 오늘자 대시보드에 주입하는 행위를 원천 금지합니다. 대시보드의 모든 가격은 당일 라이브 웹 응답(HTTP 200) 및 실시간 DOM 추출을 거쳐 검증된 최신 데이터만 수록됩니다.

1. 가격 유형 정의 (Price Types: Raw vs Net)

기본 기준 명목 판매 가격

판매가 (Raw Selling Price)

유통사 웹사이트 상품 상세 페이지(PDP)에 대문짝만하게 명시된 기본 결제 가격입니다. 별도의 장바구니 할인 쿠폰이나 제조사 사후 환급 캐시백이 반영되기 전의 공식 표기 판매가입니다.

포함 내역: 일반 웹사이트 표시 판매가 (취소선 정가 제외)

실질가 / 실구매가 (Net Price)

소비자가 제품을 구매할 때 최종적으로 지불하거나 환급받아 체감하는 실질 구매 가격입니다. Net Price = 판매가 - 장바구니 즉시할인(Direct Cut) - 제조사/유통사 환급 캐시백

💡 영업 실무 팁: 유럽 유통(특히 프랑스/스페인/독일)은 공식 판매가를 건드리지 않고 200~500€ 상당의 캐시백이나 장바구니 10% 쿠폰으로 실질적인 가격 공세를 펼치는 경우가 많으므로, 경쟁사 대비 진정한 가격 포지셔닝은 반드시 실질가(Net)로 확인해야 합니다.

2. 핵심 가격 지표 및 수식 (Key Metrics & Formulas)

엘지와 삼성의 라인업 간 가격 우열을 판단하는 표준 지수 및 계산식

ATA 지수 (Against Target / Samsung Index)

ATA = ( LG 모델 가격 / 삼성 대항모델 가격 ) × 100
  • • ATA = 100: LG와 삼성의 가격이 완전 동일 (Parity)
  • • ATA > 100: LG가 삼성보다 고가 (예: ATA 110 = LG가 10% 비쌈)
  • • ATA < 100: LG가 삼성보다 저가 (예: ATA 90 = LG가 10% 저렴)

가격 GAP (Price Difference)

GAP = LG 최근가 - Samsung 최근가
  • • 양수 (+): '엘지 고가' 상태 (LG가 해당 금액만큼 비싸게 판매 중)
  • • 음수 (-): '삼성 고가' 상태 (LG가 해당 금액만큼 저렴하여 가격 우위)
  • • 차트 클릭 시 팝업되는 모달 하단에서 자동 계산 라벨 제공

실무 계산 예시: 65인치 플래그십 OLED (LG G6 vs. Samsung S95H)

1) 판매가(Raw Price) 기준 비교
• LG OLED65G6 판매가: €2,499
• Samsung 65S95H 판매가: €2,399
➔ GAP = +€100 (엘지 고가) / ATA = 104.2
2) 실질가(Net Price: 캐시백 €200 적용) 기준 비교
• LG OLED65G6 실질가: €2,299 (캐시백 €200 차감)
• Samsung 65S95H 실질가: €2,399 (캐시백 없음)
➔ GAP = -€100 (삼성 고가) / ATA = 95.8 (LG 가격 경쟁 우위)
